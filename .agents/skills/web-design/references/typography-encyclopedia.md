# Typography Encyclopedia

Catálogo exhaustivo de typefaces por categoría, personalidad y mejores pairings. Todas las fuentes son de **Google Fonts** para máxima accesibilidad.

---

## Categorías Principales

### 1. Geometric Sans
**Características**: Formas basadas en geometría pura, círculos perfectos, líneas limpias.
**Personalidad**: Moderna, tecnológica, minimalista, progresiva.
**Cuándo usarla**: Tech startups, apps de productividad, dashboards, marcas innovadoras.

| Fuente | Personalidad | Mejor Pairing | Evitar Para |
|--------|--------------|---------------|-------------|
| **Outfit** | Moderna pero cálida. Versátil, excelente legibilidad. | Source Sans 3, Space Grotesk | Bancos tradicionales |
| **Space Grotesk** | Técnica, futurista. Good para datos y código. | Inter (solo si necesario), DM Sans | Luxury brands |
| **DM Sans** | Geométrica con personalidad. Low contrast. | DM Serif Display, Playfair | Textos largos sin interlineado extra |
| **Poppins** | Friendly, circular. Muy popular (uso con moderación). | Poppins (bold for display), normal para UI | Ya está en todos lados |
| **Manrope** | Variable, moderna. Excelente para interfaces. | Manrope itself (variable weights) | Proyectos que buscan diferenciación |

**⚠️ Overused Alert**: Poppins está saturado en 2024-2025. Considerar Outfit o Manrope como alternativas más frescas.

---

### 2. Humanist Sans
**Características**: Basadas en caligrafía romana, formas orgánicas, alta legibilidad.
**Personalidad**: Amigable, accesible, humana, profesional sin ser fría.
**Cuándo usarla**: Healthtech, educación, apps consumer-facing, contenido editorial.

| Fuente | Personalidad | Mejor Pairing | Evitar Para |
|--------|--------------|---------------|-------------|
| **Source Sans 3** | Profesional, muy legible. La "Helvetica libre". | Cualquier display font, funciona como body universal | Proyectos que necesitan más personalidad |
| **Nunito** | Redondeada, friendly. Muy legible. | Nunito (bold for display), any serif | Ya muy común en educación |
| **Open Sans** | Clásica, safe choice. Google default. | Roboto Slab, Merriweather | Literalmente en todos lados |
| **Lato** | Elegante pero accesible. "Serious but not boring". | Lato itself (display weights) | Un poco datado (2010s vibe) |
| **Karla** | Quirky pero legible. Interesante para proyectos creativos. | Karla + Playfair Display | Corporate conservative |

**⚠️ Overused Alert**: Open Sans y Nunito son ubicuos. Source Sans 3 es más moderno.

---

### 3. Sans Serif Moderno / Neo-Grotesque
**Características**: Derivadas de Helvetica/Univers, neutrales, funcionales.
**Personalidad**: Profesional, limpia, invisible pero efectiva.
**Cuándo usarla**: Enterprise, SaaS B2B, documentación, dashboards complejos.

| Fuente | Personalidad | Mejor Pairing | Evitar Para |
|--------|--------------|---------------|-------------|
| **Inter** | La "nueva Helvetica". Optimizada para pantallas. | Funciona sola, o con cualquier serif | **OVERUSED** — default que debes justificar |
| **Roboto** | Android default. Geométrica-humanist hybrid. | Roboto Slab, Roboto Mono | Igual que Inter |
| **IBM Plex Sans** | Corporate pero con carácter. Open source IBM. | IBM Plex Mono, IBM Plex Serif | Startups que necesitan más punch |
| **Overpass** | Diseñada para señalización de carreteras → excelente legibilidad. | Overpass Mono | Proyectos que necesitan más personalidad |
| **Work Sans** | Moderna, elegante. Good para fintech. | Libre Baskerville, Cormorant | Proyectos muy técnicos |

**⚠️ CRITICAL**: Inter y Roboto son defaults LAZY. Solo usar si:
- El proyecto explícitamente las pide
- Necesitas máxima compatibilidad/legibilidad y no hay brand personality
- Es un proyecto interno/herramienta donde la neutralidad es el objetivo

**Alternativas a Inter**: Outfit, Manrope, Space Grotesk, DM Sans.

---

### 4. Transitional Serif
**Características**: Puente entre serif antiguo y moderno. Balanceado, elegante.
**Personalidad**: Profesional, confiable, con herencia editorial.
**Cuándo usarla**: Editorial, law firms, consultoría, finance, luxury.

| Fuente | Personalidad | Mejor Pairing | Evitar Para |
|--------|--------------|---------------|-------------|
| **Libre Baskerville** | Clásica, elegante. Web-optimized Baskerville. | Work Sans, Outfit | Proyectos muy modernos |
| **Lora** | Editorial, elegante. Muy popular. | Lora itself, o con sans modern | Overused en blogs |
| **Crimson Pro** | Académica, refinada. Good para texto largo. | Crimson Pro (variable), Outfit | Interfaces que necesitan más punch |
| **Source Serif 4** | Adobe's opensource. Muy legible. | Source Sans 3 (perfect pairing) | Proyectos que necesitan más personalidad |
| **Spectral** | Versátil, excelente para reading. Google/TypeNetwork. | Spectral itself (variable) | Headlines grandes (mejor para body) |

---

### 5. Slab Serif
**Características**: Serif con bloques rectangulares en los extremos.
**Personalidad**: Robusta, industrial, confident, con presencia.
**Cuándo usarla**: Tecnología con heritage, editorial bold, startups que quieren diferenciarse.

| Fuente | Personalidad | Mejor Pairing | Evitar Para |
|--------|--------------|---------------|-------------|
| **Roboto Slab** | Familiar (Google ecosystem). Moderna. | Roboto, Roboto Mono | Proyectos fuera de Google ecosystem que necesitan más character |
| **Zilla Slab** | Mozilla brand font. Tech + editorial. | Zilla Slab Highlight (display) | Proyectos que no quieren vibe Mozilla |
| **MuseoModerno** | Geométrica, tech-forward. Única. | Cualquier sans geometric | Texto pequeño (mejor display) |
| **Bitter** | Text-focused slab. Excellent legibility. | Bitter itself | Headlines (mejor body) |

---

### 6. Display / Headline Fonts
**Características**: Diseñadas para impacto, no para texto largo.
**Personalidad**: Dramáticas, expresivas, memorables.
**Cuándo usarla**: Logos, hero headlines, branding, posters.

| Fuente | Personalidad | Cuándo Usar | Pairing |
|--------|--------------|-------------|---------|
| **Playfair Display** | Elegant, editorial, luxury. | Fashion, luxury, editorial | Source Sans 3, Open Sans |
| **Cormorant** | Didot-inspired, high contrast. | Premium, fashion | Work Sans, Manrope |
| **DM Serif Display** | Moderno con character. | Tech premium, SaaS | DM Sans |
| **Abril Fatface** | Bold, editorial, retro. | Headlines impactantes | Abril Text (si disponible), Lato |
| **Syne** | Geométrica, tech, distinctive. | Tech startups, digital art | Syne itself (variable), Space Mono |
| **Bebas Neue** | Condensed, bold, impactful. | Posters, sports, headlines | Cualquier sans para body |
| **Righteous** | Retro-futuristic, quirky. | Creative projects, portfolios | Quicksand, Nunito |

---

### 7. Monospace
**Características**: Ancho fijo, técnica, código.
**Personalidad**: Técnica, developer-focused, honest.
**Cuándo usarla**: Código, datos técnicos, timestamps, developer tools.

| Fuente | Personalidad | Mejor Uso | Pairing |
|--------|--------------|-----------|---------|
| **JetBrains Mono** | Diseñada para código. Excellent legibility. | Code blocks, developer tools | Cualquier sans |
| **Fira Code** | Ligaduras de programación. Muy popular. | Code with ligatures | Inter, Roboto |
| **IBM Plex Mono** | Corporate tech. Clean. | Enterprise tools | IBM Plex Sans |
| **Space Mono** | Tech, distinctive. | Tech branding, quirky interfaces | Space Grotesk |
| **Source Code Pro** | Adobe's monospace. Clean, professional. | Documentation, technical content | Source Sans 3 |
| **Roboto Mono** | Google's monospace. Standard. | Android, Google ecosystem | Roboto |

## Font Pairing Guide

### Principios de Pairing

1. **Contraste de clasificación**: Geometric + Serif, Humanist + Slab
2. **Contraste de peso**: Display bold + Body regular
3. **Evitar conflicto**: No usar dos fonts con personalidad fuerte
4. **Mismo sistema**: Fonts de la misma familia (variable fonts) siempre funcionan

### Pairings Recomendados por Arquetipo

#### 🚀 Tech Startup / SaaS
- **Display**: Space Grotesk Bold / Outfit Bold
- **Body**: Inter / Source Sans 3 / Manrope
- **Mono**: JetBrains Mono / Space Mono

#### 💼 Enterprise / B2B
- **Display**: Libre Baskerville / IBM Plex Serif
- **Body**: IBM Plex Sans / Source Sans 3
- **Mono**: IBM Plex Mono

#### 💰 Finance / Fintech
- **Display**: DM Serif Display / Cormorant
- **Body**: Work Sans / Manrope
- **Accent**: Crimson Pro

#### 🎨 Creative Agency / Portfolio
- **Display**: Syne / Playfair Display / Cormorant
- **Body**: Outfit / DM Sans
- **Mono**: Space Mono

#### ☕ Lifestyle / Consumer Brand
- **Display**: Nunito (bold) / Poppins (bold)
- **Body**: Nunito / Source Sans 3
- **Accent**: A serif for headlines

#### 📰 Editorial / Blog
- **Display**: Lora / Crimson Pro / Spectral
- **Body**: Source Serif 4 / Lora
- **Accent**: Un sans para UI elements

#### 🏥 Health / Wellness
- **Display**: Outfit / Manrope
- **Body**: Source Sans 3 / Lato
- **Evitar**: Cualquier cosa muy técnica

#### 🎮 Gaming / Entertainment
- **Display**: MuseoModerno / Righteous / Syne
- **Body**: Space Grotesk / DM Sans
- **Mono**: JetBrains Mono (stats, data)

## Escalas Tipográficas Recomendadas

### Mobile-First Scale
```
--text-xs: 0.75rem;    /* 12px */
--text-sm: 0.875rem;   /* 14px */
--text-base: 1rem;     /* 16px */
--text-lg: 1.125rem;   /* 18px */
--text-xl: 1.25rem;    /* 20px */
--text-2xl: 1.5rem;    /* 24px */
--text-3xl: 1.875rem;  /* 30px */
--text-4xl: 2.25rem;   /* 36px */
--text-5xl: 3rem;      /* 48px */
--text-6xl: 3.75rem;   /* 60px */
```

### Desktop Scale (para headings más grandes)
```
--text-7xl: 4.5rem;    /* 72px */
--text-8xl: 6rem;      /* 96px */
--text-9xl: 8rem;      /* 128px */
```

### Line Height
```
--leading-tight: 1.2;   /* Headings */
--leading-snug: 1.4;     /* Subheadings */
--leading-normal: 1.5;   /* Body */
--leading-relaxed: 1.75; /* Long-form content */
```

## Variable Fonts (Recomendadas)

Las variable fonts ofrecen múltiples pesos en un solo archivo, reduciendo carga y ofreciendo flexibilidad.

| Variable Font | Weights | Mejor para |
|---------------|---------|------------|
| Outfit | 100-900 | Tech, modern interfaces |
| Manrope | 200-800 | Clean, professional |
| Space Grotesk | 300-700 | Tech, data-heavy |
| Syne | 400-800 | Creative, distinctive |
| Work Sans | 100-900 | Fintech, enterprise |
| Crimson Pro | 200-900 | Editorial, long-form |

## Google Fonts Links Template

Para usar en HTML:
```html
<!-- Pairing: Outfit + Source Sans 3 -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700&family=Source+Sans+3:wght@400;500;600&display=swap" rel="stylesheet">
```

Para CSS:
```css
:root {
  --font-display: 'Outfit', sans-serif;
  --font-body: 'Source Sans 3', sans-serif;
}

h1, h2, h3 { font-family: var(--font-display); }
body { font-family: var(--font-body); }
```
